moj-comp no treino livre — escolha, leia, resolva e envie sem sair do terminal

Esta é a mesma CLI usada nos contests, no modo treino. Busque no banco público, baixe o enunciado, envie e receba o veredicto no terminal. Use a sua conta do site e o seu $EDITOR de sempre.

Conteúdo 1. Instalar e entrar 2. Achar um problema 3. Ler, resolver, enviar 4. Comandos rápidos 5. Dicas

1. Instalar e entrar (um minuto)

curl -fsSL https://moj.naquadah.com.br/moj-comp -o ~/.local/bin/moj-comp && chmod +x ~/.local/bin/moj-comp
moj-comp login treino           # a MESMA conta que você usa no site

Requisitos: bash, curl e jq. Todo Linux ou macOS tem esses programas. Não precisa de root. Não precisa instalar nada. A CLI é um arquivo só. Depois do login, a CLI lembra que você está no treino. Os próximos comandos não precisam de flags extras.

2. Achar um problema

moj-comp problems vetores       # busca por id/título
moj-comp problems fibonacci
# moj-problems#fibonacci-memoizacao   Fibonacci   13 resolveram

Cada problema tem um id na forma org#slug (por exemplo apc#vetor1). Use esse id para ler e para enviar. Para navegar por coleções e tags, use o site (/treino). Use a CLI para o ciclo de envio.

3. Ler, resolver, enviar — o ciclo

moj-comp statement apc#vetor1   # salva ./vetor1.html — abra no navegador
$EDITOR sol.c                   # resolva no seu canto
moj-comp submit apc#vetor1 sol.c
# enviada (apc#vetor1, sol.c) — id 54ada0…. aguardando veredicto…
# veredicto: Accepted
moj-comp subs                   # seu histórico de envios e veredictos

A linguagem vem da extensão do arquivo (sol.c, sol.cpp, sol.py, Main.java). O submit espera o veredicto e imprime o resultado. O ciclo inteiro de prática fica em um terminal só.

Recebeu Wrong Answer? Abra a página da submissão no site. Ela mostra o relatório completo, teste a teste. A CLI dá o veredicto rápido. O site dá o detalhe.

4. ⚡ Comandos rápidos

ComandoO que faz
moj-comp login treinoentra com a sua conta do site (fica lembrado)
moj-comp problems <busca>busca no banco público (id, título, quantos resolveram)
moj-comp statement <org#slug>baixa o enunciado em HTML
moj-comp submit <org#slug> <arquivo>envia e espera o veredicto
moj-comp subsseus envios e veredictos
moj-comp doctor · updatediagnóstico · auto-atualização

5. 💡 Dicas

  • Vai competir? A mesma CLI funciona nos contests: placar, clarifications e mais. Leia o guia em /contest/cli.html.
  • O moj-comp update mantém a CLI atualizada. O moj-comp doctor diagnostica problemas no seu ambiente. A CLI também avisa sozinha quando está desatualizada.
  • Você pode usar a CLI em scripts. Ela é bash, curl e jq puros. Faça um loop na sua lista de exercícios e envie cada solução.
